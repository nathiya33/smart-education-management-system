# Smart Education Management System

## 📌 Project Overview

The Smart Education Management System is a web-based application
designed to simplify educational activities and reduce manual work.

It provides role-based access for administrators, teachers, students,
and parents. The system includes face-recognition-based attendance
tracking to improve attendance management and communication.

## 🎯 Objectives

- Digitize educational management activities.
- Reduce manual attendance work.
- Track student attendance using face recognition.
- Improve communication between teachers, students, and parents.
- Maintain student and academic information efficiently.

## 👥 User Modules

### 1. Admin
- Manage student and teacher information.
- Manage classes and educational records.
- Monitor overall system activities.

### 2. Teacher
- View student information.
- Manage student attendance.
- Update academic information.

### 3. Student
- View personal information.
- Check attendance records.
- View available academic information.

### 4. Parent
- View their child's attendance.
- Monitor academic progress.
- Access available student information.

## 🤖 Face Recognition Attendance

The system uses face recognition to support student attendance
tracking.

Python and OpenCV are used for face recognition. Recognized
student information can be associated with attendance records
stored in the database.

This feature aims to reduce manual attendance entry and improve
attendance management.

## 🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Face Recognition: Python, OpenCV
- Dependency Management: Composer

## 🗄️ Database

MySQL is used to store and manage student information, teacher
information, attendance records, and other relevant educational data.

## 🔐 Authentication

The application provides login access for four user roles:

- Admin
- Teacher
- Student
- Parent

Each role is intended to access the features relevant to its
responsibilities.
